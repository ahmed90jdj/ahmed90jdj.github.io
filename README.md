## Running Locally

You can run this website locally using one of the following methods:

### Method 1: Using the shell script
```bash
./serve.sh
```

### Method 2: Using npm
```bash
npm start
# or
npm run serve
# or
npm run dev
```

### Method 3: Using Python directly
```bash
python3 -m http.server 8000
```

After running any of these commands, open your browser and navigate to:
```
http://localhost:8000
```

## Files
- `index.html` - Main resume page
- `Product Engineer at ALTEN Resume Sample.pdf` - Resume PDF file
- `serve.sh` - Shell script to run local development server
- `package.json` - NPM configuration with scripts
